# Feature modules

Fitur dari index SellerBooks lama akan dipetakan ke modul-modul di folder ini, misalnya:
- dashboard
- laporan dan rincian penjualan
- marketplace dan akun toko
- master produk
- impor penjualan dan tarik order API
- biaya lain dan packing
- pengaturan, backup/restore, dan bahasa
- piutang
- analytics

File fitur akan dibuat setelah audit ketergantungan fungsi, elemen DOM, dan state selesai. Jangan memindahkan kode secara massal sebelum pemetaan dan pengujian agar tidak merusak alur data.
